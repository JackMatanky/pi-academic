# academic-writer Gemini MCP server

Internal MCP server bundled inside the academic-writer pi package. Routes the package's reader-facing prose phases — section drafting + 6 in-pipeline quality checks, cross-section synthesis, free-form edits, and voice calibration samples — to Gemini, while the orchestrating agent retains overall control and the citation audit. `extensions/lifecycle/mcp.ts` spawns this server automatically (registered as `gemini-api` in a programmatic `pi-mcp-adapter` config, with `directTools: true` and `toolPrefix: "none"` so its tools register by bare name); subagents granted `mcp:gemini-api` in their frontmatter inherit access to its five tools (`gemini_write_section`, `gemini_synthesize`, `gemini_edit`, `gemini_calibrate_sample`, `gemini_raw`). Auth, calibration-bundle caching, retry, and the 2.5 / 3.x thinking-API split are handled internally. Setup is owned by the `/skill:academic-writer-setup` skill.
